# BHL Year

A 365-day "ready for anything" training program, numbered Day 1 to Day 365, delivered as a phone-first web app. It reproduces the structure and progression logic of a 2019 coached program (BHL) and does the coach's arithmetic for you: ladders start where last week ended, waves and deloads use your tested maxes, rowing, bike, and run targets come from your own tests.

## Running tests

    npm test

## Serving locally

    npm run serve

then open <http://localhost:8080>.
